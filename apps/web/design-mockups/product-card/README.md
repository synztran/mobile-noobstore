# Product-card mockups

Two standalone, non-production desktop concepts informed by the current `ProductCard` components. Open either HTML file directly in a browser; no build or server required.

The product names, prices, stock, variants, and ratings below are clearly marked illustrative sample data, not live catalog data or product claims. Images use stable Unsplash source URLs for visual direction only.

- `01-build-bench.html` — compact workbench card with image-led hierarchy.
- `02-spec-editorial.html` — wider editorial comparison row with split image and purchase rail.

Both pages are designed for desktop, with a narrow-width fallback to prevent overflow. No production components are modified.
